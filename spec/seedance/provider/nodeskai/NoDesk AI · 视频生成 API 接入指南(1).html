🎬 服务概览

NoDesk AI 视频生成 API 提供基于豆包 Seedance 2.0 的 AI 视频生成能力，支持：

  • 文生视频 — 输入文字描述，生成对应视频
  • 图生视频 — 提供参考图片 + 文字描述，让静态图片动起来
  • 多种参数 — 自定义分辨率、时长、宽高比
  • 两种模型 — 标准版（高画质）和快速版（低延迟）

🔄 调用流程

1
提交生成任务

POST /v1/video/generate → 返回 task_id

2
轮询等待结果

GET /v1/video/generate/{task_id} → 每 30-60 秒轮询一次

3
获取视频

状态变为 succeeded 后，从响应中获取 video_url 下载视频

异步生成：视频生成是异步任务。快速版约 1-3 分钟，标准版约 3-10 分钟。请通过轮询获取结果，不要阻塞等待。
🔑 认证方式

所有 API 请求需要在 HTTP Header 中携带 API Key：

# 请求头 Authorization: Bearer {YOUR_API_KEY}
获取 API Key：请联系管理员创建项目和 API Key，并确保账户已充值。余额不足时 API 将返回 HTTP 402 错误。

响应示例：

Step 2 · 轮询任务状态（每 30-60 秒一次）

📝 参数详解

content 数组 — 支持多模态输入

content 是一个数组，每个元素描述一种输入。系统会根据包含的类型自动识别生成模式。

type用途子字段说明
text文本提示词text: string 描述视频内容，支持中英文。建议详细描述场景、动作、光影
image_url参考图片image_url.url: string 提供参考图片 URL，实现图生视频。支持 JPG/PNG/WebP
video_url参考视频video_url.url: string 提供参考视频 URL，实现视频续写或风格迁移
生成模式自动识别：
仅有 text → 文生视频
text + image_url → 图生视频（让图片动起来）
包含 video_url → 视频续写 / 风格迁移

ratio（宽高比）可选值

值说明适用场景
16:9横屏（默认）PC 端、视频网站
9:16竖屏手机端、短视频平台
1:1方形社交媒体
4:3 / 3:4传统比例特殊场景

resolution（分辨率）

分辨率说明Token 消耗对比
720p（默认）高清基准
1080p全高清约为 720p 的 2.3 倍
📊 Token 消耗说明

Token 计算逻辑

视频生成的 Token 消耗与分辨率、帧率、时长成正比。系统会在 API 响应的 usage.completion_tokens 字段中返回实际消耗的 Token 数。

不同参数组合的 Token 参考

参数组合分辨率时长预估 Token
默认参数720p5s ~108,900
长视频720p10s ~221,184
高清1080p5s ~248,832
高清长视频1080p10s ~497,664
无需自行计算：API 响应中的 usage.completion_tokens 就是实际消耗量，具体费用以账单为准。

🧊 预冻结机制

提交任务时系统会预冻结一定额度的余额，视频生成完成后自动结算：解冻预冻金额 → 按实际 Token 消耗扣费。

  • 生成成功：解冻预冻额度 → 扣除实际费用
  • 生成失败：全额解冻，不扣费
  • 余额不足时提交任务会返回 HTTP 402

🔄 示例 5：轮询 + 下载（完整脚本）

#!/bin/bash # 替换为你的 API Key 和 Task ID API_KEY="{YOUR_API_KEY}" TASK_ID="{TASK_ID}" BASE="https://llm-gateway-api.nodesk.tech" # 轮询直到完成 while true; do RESP=$(curl -s "$BASE/v1/video/generate/$TASK_ID" \ -H "Authorization: Bearer $API_KEY") STATUS=$(echo "$RESP" | python3 -c "import sys,json; print(json.load(sys.stdin).get('status',''))") echo "状态: $STATUS" if [ "$STATUS" = "succeeded" ]; then VIDEO_URL=$(echo "$RESP" | python3 -c "import sys,json; print(json.load(sys.stdin)['content']['video_url'])") echo "视频 URL: $VIDEO_URL" curl -o output.mp4 "$VIDEO_URL" echo "视频已保存为 output.mp4" break elif [ "$STATUS" = "failed" ]; then echo "生成失败" echo "$RESP" break fi echo "等待 30 秒后重试..." sleep 30 done
⚠ 错误处理
HTTP 状态码错误码说明处理建议
401unauthorized API Key 无效或未提供 检查 Authorization Header 格式
402insufficient_balance 账户余额不足 联系管理员充值，确保余额充足
400bad_request 请求参数有误 检查 content 数组是否为空、参数格式
500internal_error 服务器内部错误 稍后重试，或联系技术支持
任务失败时的响应中包含 error.code 和 error.message 字段，请查看错误信息进行排查。常见原因包括：图片 URL 无法访问、提示词违规等。
❓ 常见问题

Q: 视频生成需要多长时间？

快速版约 1-3 分钟，标准版约 3-10 分钟。1080p 和长时长视频会更慢。

Q: 视频 URL 有效期多久？

签名 URL 有效期 24 小时。请在生成成功后及时下载保存，过期后需重新生成。

Q: 生成失败会扣费吗？

不会。生成失败时预冻结的余额会全额退还，不产生任何费用。

Q: 如何估算消耗？

Token 消耗与分辨率、时长成正比。720p/5s 的视频约消耗 108,900 Token，1080p/10s 约 497,664 Token。 具体数值由 API 响应的 completion_tokens 字段返回，具体费用以账单为准。

Q: 支持哪些图片格式？

图生视频支持 JPG、PNG、WebP 格式，建议图片分辨率 ≥ 720p，图片 URL 需要可公开访问。

Q: 提交任务后没有轮询会怎样？

预冻结的余额不会自动释放。必须通过轮询触发结算。建议在提交任务后立即开始轮询。

Q: 如何获取 API Key 和充值？

请联系管理员。管理员会为您创建项目、生成 API Key 并充值余额。

API 地址：https://llm-gateway-api.nodesk.tech
